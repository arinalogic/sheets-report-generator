# Генератор отчётов

Tkinter-приложение генерирует случайный отчёт о продажах за выбранный период и записывает его на новый оформленный лист Google Таблицы. В отчёте есть параметры, список сделок и итоги; заголовки, цвета, границы, ширина столбцов и денежный формат задаются через Google Sheets API.

## Структура проекта

- `google_sheets.py` — класс `GoogleSheets` для чтения, записи и оформления листов Google Таблицы.
- `report_generator.py` — графическое приложение и генерация отчётов.
- `requirements.txt` — зависимости Python.
- `.env.example` — образец переменных окружения (без настоящих значений).

## Настройка

### 1. Подготовьте Google Cloud

1. Создайте проект в [Google Cloud Console](https://console.cloud.google.com/) или выберите существующий.
2. В разделе API включите **Google Sheets API**.
3. Создайте сервисный аккаунт и назначьте ему роль **Editor**.
4. Откройте сервисный аккаунт, создайте JSON-ключ и скачайте файл. Храните его в корне проекта под именем `service_account.json` или укажите другой путь в настройках ниже.

### 2. Создайте таблицу и выдайте доступ

Создайте Google Таблицу. В настройках доступа таблицы добавьте адрес `client_email` из JSON-ключа и назначьте ему роль **Редактор**. Роль Editor в Google Cloud сама по себе не предоставляет сервисному аккаунту доступ к конкретной таблице.

ID таблицы находится в адресе между `/d/` и `/edit`:

```text
https://docs.google.com/spreadsheets/d/<SPREADSHEET_ID>/edit
```

### 3. Настройте переменные окружения

В корне проекта лежит образец .env.example со следующим содержимым:

```dotenv
GOOGLE_CREDENTIALS_PATH=service_account.json
SPREADSHEET_ID=вставьте_сюда_ID_таблицы
```

Скопируйте образец в `.env` и замените `вставьте_сюда_ID_таблицы` на ID своей таблицы. Если JSON-ключ находится в другом месте, укажите его путь в `GOOGLE_CREDENTIALS_PATH`.

```powershell
Copy-Item .env.example .env
```

### 4. Создайте виртуальное окружение и установите зависимости

В PowerShell из корня проекта выполните:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell запрещает активацию окружения, можно установить зависимости напрямую через исполняемый файл окружения:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 5. Запустите приложение

```powershell
python report_generator.py
```

Укажите даты в формате `YYYY-MM-DD`, выберите тип отчёта и отдел, заполните ответственное лицо и при необходимости комментарий. При генерации приложение создаст новый лист в указанной таблице.

## Методы `GoogleSheets`

- `get_sheet_names()` возвращает названия листов.
- `read_range()` и `read_all_cells()` читают данные; `write_range()` записывает диапазон, по умолчанию используя `RAW`.
- `update_cell()`, `append_row()` и `clear_range()` изменяют содержимое ячеек.
- `add_sheet()` создаёт лист, `delete_sheet()` удаляет его.
- `format_range()` задаёт фон, цвет и размер шрифта, жирность и горизонтальное выравнивание.
- `merge_cells()` объединяет ячейки, `set_borders()` устанавливает границы.
- `set_column_width()` задаёт ширину столбцов в пикселях, `set_number_format()` устанавливает числовой формат.

Методы форматирования принимают диапазон вместе с названием листа, например `'Лист 1'!A1:F1`.

## Безопасность

- Не добавляйте `.env` и JSON-ключ сервисного аккаунта в репозиторий и не публикуйте их. Текущий `.gitignore` уже исключает `.env`, `service_account.json` и некоторые шаблоны JSON-ключей. Если используете другое имя или расположение ключа внутри проекта, убедитесь, что оно также исключено из Git.
- Не вставляйте ключ, ID таблицы или содержимое `.env` в исходный код, README, сообщения об ошибках или публичные обсуждения.
- Если JSON-ключ был опубликован или передан посторонним, отзовите его в Google Cloud Console: **IAM и администрирование → Сервисные аккаунты → нужный аккаунт → Ключи**, удалите скомпрометированный ключ и создайте новый. Обновите локальный JSON-файл и проверьте доступ сервисного аккаунта к таблице.
